# 文档复审管理台

本页面汇总所有文档的复审状态。数据来自后台按**发布版**生成的任务快照
（`docs/public/review-manifest.json`，由 `npm run review:seed` 导出）。

## 状态与规则说明

| 状态 | 含义 |
| :--- | :--- |
| 已复审 | 当前发布版无打开任务，公开日期来自最近一次真实签收 |
| 复审中 | 任务已生成，审阅项尚未覆盖声明范围 |
| 即将到期 | 距到期日 ≤ 3 天（黄色提示） |
| 已超期 | 已严格越过到期日（按站点时区日历日） |
| 部分检查失败 | 存在 failed 审阅项，禁止签收 |
| 无继任负责人 | 负责人离职 / 小组调整后暂无人接手 |

关键规则：

1. **两类任务合并**：固定周期扫描与依赖变更触发，在同一发布版内合并为一条任务。
2. **重复触发幂等**：相同发布版/文档/依赖/内容版本的重复投递安全重放，提醒任务重跑只累加次数。
3. **检查一处不等于整篇**：正文、每个示例、每张图、每张表都是独立审阅项，图必须被 frontmatter 声明范围覆盖才允许签收。
4. **关键变化只影响相关项**：正文或依赖更新后，相关项回到待重验，其它项和历史签收保留。
5. **责任交接不覆盖签收者**：离职 / 小组调整只转派待办；签收、交接、证据全部 append-only（PG 触发器禁止 UPDATE/DELETE）。
6. **到期不撤内容**：复审到期只提示「信息需核实」，历史公开内容继续可读；公开日期与校验范围反映真实完成范围。
